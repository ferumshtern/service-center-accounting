# Система обліку сервісного центру електроніки


## Призначення системи
Програмна система для автоматизації процесів обліку та гарантійного обслуговування пристроїв у сервісному центрі електроніки. Забезпечує реєстрацію замовлень, відстеження статусів ремонту, облік виконаних робіт і розрахунок їхньої вартості.

## Структура рішення

* `src/ServiceCenter.Api` — серверний Web API застосунок для управління бізнес-логікою, замовленнями та статусами робіт.
* `src/ServiceCenter.Client` — клієнт для взаємодії з API та тестування ендпоінтів.
* `tests/ServiceCenter.Tests` — автоматизовані модульні тести на базі xUnit.
* `docs/` — проєктна документація, регламент розробки та розподіл обов'язків команди.
* `.github/workflows/ci.yml` — конфігурація автоматизованого конвеєра збірки та тестування (GitHub Actions).

## Вимоги до середовища
* .NET SDK 9.0+
* Git

## Локальна перевірка та запуск

1. Відновлення залежностей:

'dotnet restore'


2. Компіляція проєкту:

'dotnet build --no-restore'


3. Запуск модульних тестів:

'dotnet test --no-build'


4. Запуск серверного API:

'dotnet run --project src/ServiceCenter.Api'


5. Запуск консольного клієнта:


'dotnet run --project src/ServiceCenter.Client'
