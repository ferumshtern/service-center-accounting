# Матриця простежуваності вимог (RTM) — Випуск v1.0.0

> **Після спринту S1 (ЛР №5).** Матриця фіксує стан випуску v1.0.0. У S1 `ServiceStore` замінено контрактом `IOrderRepository` (`InMemoryOrderRepository` для модульних тестів, `SqliteOrderRepository` — основне сховище сервера), тести `ServiceStoreTests` перейменовано на `InMemoryOrderRepositoryTests` з тими самими назвами методів. Перевірку історії спринту S1 наведено в [`sprints/s1.md`](sprints/s1.md).

Матриця ЛР №3 (`requirements-baseline-v1.0`) доповнена стовпцями ЛР №4. Перші чотири стовпці (вимога, сценарій, критерій приймання, проєктний артефакт) збережено без змін. Нові стовпці: реалізований компонент, перевірка та фактичний результат. Докладні вхідні дані й спостереження наведено в протоколі приймання: [`implementation.md`, розд. 4](implementation.md#4-протокол-приймальних-перевірок-інтегрованої-версії-v100). Кроки клієнта — це нумеровані кроки `src/ServiceCenter.Client/Program.cs`.
