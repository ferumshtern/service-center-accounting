\## Регламент взаємодії

\* \*\*Модель розробки:\*\* Feature Branch Workflow. Прямі коміти в гілку `main` заборонені.

\* \*\*Рецензування (Code Review):\*\* Кожен PR перевіряється другим учасником команди. Автор передає задачу на тестування та перевірку документації, після чого напарник виставляє статус \*\*Approved\*\*.

\* \*\*Контроль якості (CI):\*\* Автоматична збірка та модульні тести в GitHub Actions мають бути успішними перед злиттям змін.
